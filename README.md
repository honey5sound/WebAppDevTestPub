# 사흘 날씨

기상청 단기예보 API로 선택한 지역과 날짜부터 3일간의 날씨를 보여주는 웹사이트입니다.

## 실행 방법

1. [기상청 API허브 단기예보](https://apihub.kma.go.kr/apiList.do?seqApi=10)에서 단기예보 API를 활용 신청한 뒤 인증키를 발급받습니다.
2. `.env.example` 파일을 복사해 `.env`로 이름을 바꾸고 인증키를 입력합니다.
3. 터미널에서 `npm start`를 실행한 뒤, 브라우저에서 `http://localhost:3000`을 엽니다.

인증키는 서버에서만 사용되며 브라우저에 전달되지 않습니다. 단기예보는 기상청 발표 시각을 기준으로 조회됩니다.
